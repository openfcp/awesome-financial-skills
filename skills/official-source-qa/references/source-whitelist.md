# 信源分层与域名白名单

## 分层与采信规则

| 层级 | 内容 | 采信规则 |
|---|---|---|
| L1 法规与监管 | 法律、行政法规、部门规章、监管规范性文件、监管问答 | 可单源采信，需注明文号与生效日期 |
| L2 机构官方 | 官网公告、产品说明书、合同条款、招募说明书、费率表、官方公示 | 可单源采信，须以条款原文为准；公告与条款冲突时以生效日期晚者为准并提示 |
| L3 行业协会 | 行业协会自律规则、业务指引、统计口径 | 需与 L1/L2 相互印证 |
| L4 官方客服 FAQ | 官网帮助中心、官方公众号答复、官方客服话术 | 仅作辅助，不得单独作为答复依据 |

原则：**从 L1 往 L4 依次检索，命中即停**。能用 L1 说清的问题不要引 L4。

## 检索技巧

- 关键词用官方术语：客户说"提前取出来"，检索用"提前赎回""解约""退保"。
- 政策类优先找"原文 + 附件"，不要用新闻通稿和解读稿代替原文。
- 产品类以《产品说明书》《条款》《招募说明书》为准，**不以宣传页、营销海报为准**。
- 涉及时间节点的问题，同时确认文件的生效日期与是否被后续文件修订。
- 同一事项在新旧文件并存时，取生效日期最新的，并提示客户旧口径已废止。

## 不可采信

百科类站点、问答社区、自媒体与公众号解读、券商研报转述、搜索结果摘要与 AI 摘要、二手转载且无法回溯到原文的页面。上述内容可作线索，但必须回到官网原文核对后才能写进答复。
