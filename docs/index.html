WorkBuddy 技能市场
  1. 技能 → 套件 → 右上角「添加市场」，粘贴上面的清单地址
  2. 在市场里打开需要的技能卡片，点「安装」
  3. 安装完成后在对话中调用该技能
DeepSeek Harness 插件
  1. 打开 DSH →「插件」→「添加插件」
  2. 把上面的地址粘进去，确认添加（末尾 #v0.2.3 是版本号，别删）
  3. 等安装完成，彻底退出再打开 DSH 即可
如果安装不成功，，把复制的话发给对话框，让它帮你装。
单独安装 安装选项
不想装市场或插件：点卡片右下「安装 ▾」，可选 WorkBuddy 市场源 + id、DSH 安装提示词或通用提示词；粘贴到对话发送即可安装这一个技能。不提供 SkillHub CLI 复制。
  1. 在下方列表找到需要的技能，点卡片右下「安装 ▾」
  2. 按当前运行环境复制对应提示词，或复制 WorkBuddy 市场源 + id
  3. 粘贴到 WorkBuddy 或 DSH 对话框发送，装完即可调用
