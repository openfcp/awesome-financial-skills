WorkBuddy 技能市场
  1. 技能 → 套件 → 右上角「添加市场」，粘贴上面的清单地址
  2. 在市场里打开需要的技能卡片，点「安装」
  3. 安装完成后在对话中调用该技能

DeepSeek Harness 插件
  1. 终端执行 dsh plugin --profile desktop add github:openfcp/dsh-financial-skills
  2. 在 profile 的 dsh.profile.bundles 加入 dsh-financial-skills
  3. 彻底退出并重启 DSH，左侧栏点「金融技能」

单独安装 复制提示词
不想装市场或插件？下方每张技能卡片右下角的「复制提示词」，复制的是一条可直接安装的指令，粘贴到对话发送即可装好。
  1. 在下方列表找到需要的技能，点卡片右下「复制提示词」
  2. 粘贴到 WorkBuddy 或 DSH 对话框，直接发送
  3. 等它取回正文并装到技能目录，装完即可调用
