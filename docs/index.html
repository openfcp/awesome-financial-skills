  1. 清单只存引用，不含技能正文

WorkBuddy 一条命令
跑一条命令，按清单装进技能目录
  1. 终端执行上面这条命令，默认装到 ~/.workbuddy/skills
  2. 只装一个：末尾加 --only law-skills；换目录：加 --dir
  3. 先看有什么：--list；只验证引用通不通：--verify
  4. 装完刷新技能列表即可，正文每次都取最新原件
